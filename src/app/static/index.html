One claim, end to end

1. SubmitPOST /claims answers 202 at once; the assessment runs in the background and this page polls it.
→
2. ScreenRegex + LLM classifier look for prompt injection, alongside the agent.
→
3. InvestigateA ReAct agent calls MCP tools: hybrid policy search, claim history, coverage rules, fraud score. Independent calls run concurrently.
→
4. DecidePlain code sets the outcome, keeps only retrieved citations and computes confidence from evidence.
→
5. RouteAuto-finalize, or pause the LangGraph workflow for a human reviewer.
Code decides, not the LLM

If the model contradicts the deterministic coverage rules, the rules win and the claim goes to a human.

No invented citations

A clause the model cites only counts if retrieval actually returned it in this run.

Evidence-based confidence

Rules agreement, retrieval match, citation validity and fraud risk, never the model's own guess.

Fail safe

Injection, fraud signals, low confidence, a tool misuse or an LLM outage all route to a person.

Production concerns

SecurityAccess codes on REST and MCP (constant-time, fails closed), injection guardrails, tools limited to the claim under assessment, non-root container, PII redacted from logs.
ObservabilityJSON logs correlated by request and claim id (across MCP calls), token cost and latency per LLM call, optional Langfuse traces.
Evaluation40-case golden set: outcome accuracy, review-routing recall, citation validity, injection resistance, latency and cost.
ReliabilityAsync submission with failure status and restart recovery, retries and timeouts, LLM fallback to a human, daily cost cap, durable workflow state.
